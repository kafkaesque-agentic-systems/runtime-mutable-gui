High Contrast

Every element kind in each state, drawn only from the theme's roles and shape tokens. Hover lightens the track or outline; dragging shows the value bubble; focus draws the focus role; unbound draws the disabled role with a dashed outline and the missing id. “Disabled” has no separate look in version 1: the only inert state is unbound. — marks a state the kind does not have. Custom kinds draw themselves; the row shows the reference plugin’s Transfer curve. An unknown element is always drawn by the library.
